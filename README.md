# ESP32
Current Status: Incomplete (Started Early October)

This repository contains projects that use the ESP32 development board (SunFounder ESP32 Starter Kit). However, the programs are developed using Arduino IDE and wokwi (siddharthsvkm).

Components:
- ESP32
- Resistors (10Ω, 100Ω, 220Ω, 330Ω, 1KΩ, 2KΩ, 5.1KΩ, 10KΩ, 100KΩ, 1MΩ)
- Buttons
- Buzzers (Active/Passive)
- Potentiometer
- 74HC595
- LEDs/RGB
- Transistors (S8550/S8050)
- Photoresistor/Thermistor
- Tilt Switch
- Capacitor (104 F)
- Breadboard (Mini/Full)
- General Board
- Soil Moisture Module
- LCD Display
- Camera
- Speaker
- Fan
- Servo (9g)
- IR Reciever/Controller
- Motion Sensor Module
- Ultrasonic Module
- Joystick Module
- Motor
- Pump
- RGB Strip (WS2812)
- IB Obstacle Avoidance Module
- Camera Extension Board
- DHT11
- Line Tracking Module
- Audio Amplifier Module
- L292D
- Tube
- F/M Header (40-pin)
