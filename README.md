# ESP32
Current Status: Incomplete (Started Early October)

This repository contains projects that use the ESP32 development board (SunFounder ESP32 Starter Kit). However, the programs are developed using Arduino IDE.

Components:
- Arduino MEGA Controller Board
- Breadboard
- Jumper Wires
- Resistors
- LEDS
- Buzzers (Active/Passive)
- Potentiometer
- Photoresistors
- Buttons
- Servo Motor
- Switches
- LCD Module
- Joystick
- Sound Sensor
- Capacitators
- Dot Matrix
- Ultrasonic Sensor
- Water Level Detection Sensor
- Digit Display
